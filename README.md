
# FleetNest

A vehicle rental and school transport management application
for a single transport business.

## Features planned

### Vehicle rentals
- Browse vehicles and their associated driver details.
- Choose pickup location, destination and travel dates.
- Submit booking requests for owner approval.

### School transport
- Find transport by school and pickup location.
- View matching routes, available seats and driver details.
- Calculate monthly subscriptions using distance and
  owner-configured pricing.

### Business management
- Manage vehicles, drivers, routes and schedules.
- Manage booking requests and school subscriptions.
- Prevent conflicting vehicle and driver assignments.

## Technology planned

- Backend: Java and Spring Boot
- Frontend: React
- Database: PostgreSQL

## Project status

Initial setup. Features will be developed incrementally.
